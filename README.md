# TitanStudio Releases

Öffentliche Downloads und signierter Update-Feed für **TitanStudio**.

Die installierbaren Pakete für Windows, macOS und Linux befinden sich unter
[Releases](https://github.com/TitanPowered-com/titanstudio-releases/releases).
TitanStudio verwendet dasselbe Repository für automatische In-App-Updates.

Dieses Repository enthält absichtlich keinen Quellcode. Entwicklung und
Fehlerverwaltung erfolgen im privaten Hauptrepository der TitanPowered-
Organisation.

## Sicherheit

Alle Update-Artefakte werden vom privaten Release-Workflow erstellt und mit
einem eigenen TitanStudio-Schlüssel signiert. Installiere Pakete ausschließlich
aus den GitHub Releases dieses Repositories.
